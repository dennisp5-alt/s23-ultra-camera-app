# AutoPhoto Experiment v0.3 — idealized histogram push

Offline Android photo experiment. Open → Auto → Save. Tap image to compare.

Deliberately forceful histogram percentile remapping, neutral-balance correction, a strong highlight shoulder, and visibly increased saturation. This is an extreme experiment and may create unnatural colours, clipped details or banding. It is not a universally correct photographic histogram. Truly clipped highlights cannot be recovered.

Build through GitHub Actions on the isolated `autophoto-experiment` branch; existing camera app on `main` stays unchanged.
